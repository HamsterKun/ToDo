# 时笺 · ToDo

## 为什么是时笺

日程软件功能很多，打开的次数却很少；便利贴随手可写，却管不了时间。时笺取两者之长：

- **看得见**：面板放在桌面上，不用打开什么，回到桌面就能看到。
- **写得快**：像发消息一样输入「明天 9:30 交周报」，回车即可，不用点日期选择器。
- **忘不掉**：窗口铺满屏幕时，右下角的小悬浮窗始终显示最近的那条待办。

## 一句话添加，时间自动识别

<img src="docs/images/quickadd.jpg" alt="自然语言快速添加" width="100%">

在顶部输入框里写下待办，时间说法会被识别出来，剩下的部分作为标题。没写时间也没关系，它会进入「长期任务」。

| 你可以这样写 | 识别结果 |
| --- | --- |
| `今晚8点 看电影` | 今天 20:00 |
| `明天 9:30 交周报` | 明天 09:30 |
| `明天下午3点 开会` | 明天 15:00 |
| `后天`、`大后天`、`3天后`、`2周后` | 对应日期（全天） |
| `周五 9:30 周会`、`下周一 10:00 复盘`、`下下周三` | 对应的星期几 |
| `9点半`、`上午10点`、`下午2点`、`晚上8点` | 对应时刻，今天已过去的时刻自动顺延到明天 |
| `12月1日`、`12-01`、`2026-12-01`、`2026年12月1日` | 指定日期（全天） |
| `读完《设计心理学》` | 没有时间，归入长期任务 |

为了不误伤正文，`v1.2`、`3-5人`、`1.5万` 这类写法不会被当成时间。`9.30` 这种点号写法需要搭配「明天」「下午」等词才会识别，比如 `明天9.30开会`。

## 按时间自动分组，轻重缓急一目了然

<img src="docs/images/groups.jpg" alt="智能分组与编辑" width="100%">

| 分组 | 放什么 |
| --- | --- |
| **长期任务** | 没写时间的条目，始终置顶，按添加顺序排列 |
| **已逾期** | 过了时间还没完成的条目，标红显示，标题栏同步提示数量 |
| **今天 / 明天** | 今天只显示时刻，例如 `14:00`；明天带前缀，例如 `明天 20:00` |
| **接下来** | 7 天之内的安排，显示星期，例如 `周四 15:30` |
| **更远** | 一周以后的安排，显示日期，例如 `12月1日` |
| **已完成** | 勾选后收进底部，点「已完成」展开回看 |

想做但还没排期的事放进长期任务就好，不必硬塞一个日期。哪天定下来了，双击条目补上时间，它会自动挪到对应分组。

## 窗口挡住了，提醒还在

<img src="docs/images/mini.jpg" alt="迷你悬浮窗" width="100%">

时笺会留意自己是否被其他窗口挡住：

- **桌面露出时**：显示完整的毛玻璃面板，背景取自你的壁纸，看起来就像桌面的一部分。
- **被窗口遮挡时**：自动收成屏幕右下角的一行小条，只显示时间上最近的一条待办；逾期的条目以红色提示。
- **小条不打扰**：它置顶显示但不抢键盘焦点，也不会出现在任务栏和 Alt+Tab 里；点一下就回到完整面板。
- **看视频、玩游戏时**：前台是全屏应用时，小条自动隐藏。

## 更多细节

- **毛玻璃面板**：圆角、半透明、模糊壁纸作底，深色配色在各种壁纸上都清晰可读。
- **拖动与缩放**：拖动顶部移动位置，拖动右下角调整大小，位置和尺寸会被记住。
- **多屏与高分屏**：按每台显示器各自的缩放比例渲染；显示器布局变了，下次启动时窗口会被放回可见区域。
- **托盘常驻**：点右上角按钮收起到托盘；托盘菜单可以显示便签、切换开机自启（默认关闭）和退出。
- **单实例**：重复打开程序只会唤出已经在运行的那一个。
- **数据安全**：所有数据只保存在本机，不联网、不上传。写入时先写临时文件再整体替换，中途断电也不会写坏；万一数据文件损坏，会先备份再重新开始，不会悄悄覆盖。

## 安装

### 使用安装包

1. 在 [Releases](https://github.com/HamsterKun/ToDo/releases) 下载 `ToDo-Setup-x.x.x-x64.exe`。
2. 双击安装。安装包自带运行环境，无需另装 .NET，也不需要管理员权限。

卸载时在「设置 → 应用」中移除即可，你的待办数据会保留。

### 从源码构建

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download)。

```powershell
git clone https://github.com/HamsterKun/ToDo.git
cd ToDo

# 调试运行
dotnet run

# 发布为独立可执行文件（目标机器无需安装 .NET）
dotnet publish -c Release -r win-x64 --self-contained -p:PublishReadyToRun=true -o publish
```

## 使用小贴士

| 操作 | 方式 |
| --- | --- |
| 添加待办 | 在顶部输入框输入后按 `Enter`；`Esc` 清空输入 |
| 完成待办 | 点击左侧的勾选框 |
| 编辑待办 | 双击条目，或悬停后点铅笔按钮；`Enter` 保存，`Esc` 取消 |
| 转为长期任务 | 编辑时把时间清空后保存 |
| 删除待办 | 悬停后点垃圾桶按钮，或在编辑框中点「删除」 |
| 找回面板 | 点击右下角的小悬浮窗，或双击托盘图标 |

## 数据存放位置

| 文件 | 路径 |
| --- | --- |
| 待办数据 | `%AppData%\ToDo\notes.json` |
| 窗口设置 | `%AppData%\ToDo\settings.json` |
| 运行日志 | `%AppData%\ToDo\app.log` |

想备份或迁移到新电脑，复制整个 `ToDo` 文件夹即可。

## 系统要求

- Windows 10 或 Windows 11，64 位
- 使用安装包无需额外依赖；从源码构建需要 .NET 10 SDK

## 技术栈

界面使用 WPF（.NET 10），托盘使用 WinForms `NotifyIcon`；窗口遮挡检测、多屏定位和拖动缩放通过 Win32 API 实现；安装包由 Inno Setup 打包。
